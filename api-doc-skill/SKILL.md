# API 文档生成技能

## 技能名称
api-doc

## 技能描述
自动生成和更新 Markdown 格式的接口文档。支持从选中的代码中提取接口信息，自动判断接口是否已存在，支持上传 UI 截图。

## 使用方式

### 基本用法
```
/api-doc --output="./docs/api.md"
```

### 指定接口名称
```
/api-doc --output="./docs/api.md" --api-name="查询阶段报告详情"
```

## 工作流程

### Step 1: 用户准备
1. 在编辑器中选中接口代码（支持 Java、Python、Go、JavaScript 等语言）
2. （可选）在聊天窗口上传 UI 截图
3. 调用 `/api-doc --output="文档路径"`

### Step 2: 解析代码
1. 识别代码类型（Java Spring / Python FastAPI / 其他）
2. 提取 HTTP 方法和接口路径
3. 提取路径参数和查询参数
4. 提取响应结构和字段

### Step 3: 去重判断
1. 读取目标 MD 文档
2. 根据接口路径判断是否已存在
3. 如果存在：标记为更新；如果不存在：标记为新增

### Step 4: 处理图片（如有）
1. 保存上传的图片到文档目录下的 images 文件夹
2. 生成图片引用路径

### Step 5: 生成/更新文档
1. 如果是新文档：创建完整的文档结构
2. 如果是更新：替换或追加接口文档
3. 更新目录索引

## 支持的代码类型

| 语言/框架 | 示例代码 |
|-----------|----------|
| Java Spring | `@GetMapping("/api/report/{id}")` |
| Python FastAPI | `@app.get("/api/report/{id}")` |
| Express | `app.get("/api/report/:id")` |
| Go Gin | `r.GET("/api/report/:id")` |
| 纯文本 URL | `GET /api/report/{id}` |

## 接口：查询阶段报告详情

### 基本信息

| 项目 | 值 |
|------|-----|
| **接口路径** | `GET /api/report/{id}` |
| **最后更新** | 2024-01-28 10:30:00 |

### UI 截图

![截图](images/report_20240128103000.png)

### 请求参数

#### 路径参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 报告ID |

#### 成功响应（200 OK）

```json
{
  "code": 200,
  "message": "success",

| HTTP 状态码 | 说明 |

## 输入参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| --output | 是 | 输出文档路径，如 ./docs/api.md |
| --api-name | 否 | 接口名称，不指定则自动推断 |
| --code | 否 | 接口代码，默认从选中内容或剪贴板获取 |

## 注意事项

1. 确保选中的代码包含完整的接口定义
2. UI 截图会保存到文档目录下的 images 文件夹
3. 相同路径的接口会自动更新，不会重复添加
4. 生成的文档格式统一，便于拷贝和迁移

## 企业微信文档迁移方案

### 图片处理策略

#### 方案一：Base64 内联（推荐用于企业微信）
```
/api-doc --output="./docs/api.md" --image-format="base64"
```
- 将图片转为 Base64 编码直接嵌入 Markdown
- 优点：单文件，拷贝粘贴即可，无需额外上传图片
- 缺点：文档体积较大

#### 方案二：云存储托管
```
/api-doc --output="./docs/api.md" --image-upload="wecom"
```
- 自动上传图片到企业微信云盘或图床
- 生成在线图片链接
- 需要配置企业微信 API 权限

#### 方案三：本地路径（默认）
```
/api-doc --output="./docs/api.md"
```
- 图片保存到本地 `images/` 文件夹
- 适合本地查看，拷贝时需同时复制图片文件夹

### 企业微信文档最佳实践

| 场景 | 推荐方案 | 说明 |
|------|----------|------|
| 快速分享 | Base64 内联 | 单文件拷贝，直接粘贴到企业微信文档 |
| 长期维护 | 云存储托管 | 图片统一管理，支持更新 |
| 多人协作 | 云存储托管 | 团队共享图片资源 |

### 迁移步骤

1. **生成文档**（使用 Base64 格式）：
   ```
   /api-doc --output="./docs/api.md" --image-format="base64"
   ```

2. **复制内容**：
   - 打开生成的 MD 文件
   - 全选复制（Ctrl+A / Cmd+A）

3. **粘贴到企业微信文档**：
   - 打开企业微信在线文档
   - 直接粘贴，图片会自动渲染

### 生成选项扩展

| 参数 | 必填 | 说明 |
|------|------|------|
| --image-format | 否 | 图片格式：local（默认）/ base64 / url |
| --image-upload | 否 | 图片上传目标：wecom / qiniu / oss |
| --image-dir | 否 | 本地图片保存目录（默认：./images） |
